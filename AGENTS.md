# Developer & Agent Guidelines

## Project Overview
Portfolio site for Eno Osuji, Backend Engineer (`https://enoosuji.com`).

## Architecture & Code Standards
- Built with TanStack Start, React 19, Vite, and Tailwind CSS.
- Package manager: `pnpm`.
- Ensure all route changes and SEO metadata reflect `https://enoosuji.com`.
- Always verify builds with `pnpm run build` and tests with `pnpm test` before committing.
